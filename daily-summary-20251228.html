📋 Frontend Design SOP: 6-Phase Workflow

Established a complete, repeatable workflow for building production-ready frontends for AI applications. Each phase uses the optimal tool for the job.

The 6-Phase Pipeline
PHASE 1: DISCOVERY → What are we building and why? [Claude] PHASE 2: INSPIRATION → What should it look/feel like? [Mobbin] PHASE 3: DESIGN → Wireframes → Prototype JSX [Claude] PHASE 4: BUILD → v0.dev → Full React code [v0.dev] PHASE 5: INTEGRATE → Connect FE ↔ BE [Antigravity] PHASE 6: POLISH → Test, fix, iterate [Manual]
  • Discovery: JTBD statements, personas, user journeys, screen prioritization
  • Inspiration: Find north star design, extract design tokens
  • Design: Claude generates prototype JSX with inline styles
  • Build: v0.dev transforms prototypes into production Next.js code
  • Integrate: Connect to backend APIs (FastAPI + Agno)
  • Polish: Testing checklist, responsive design, error handling

⚠️ Learnings & Gotchas

Real-world insights from building the Travel Agent frontend.

  • v0 MCP Limitation: Can create new repos, but cannot push to existing repo subfolders. Use ZIP download + manual push.
  • Hydration Errors: Happen when server HTML doesn't match client. Move window and Math.random() to useEffect.
  • ZIP Extraction: v0 exports may extract files directly without parent folder. Always check with ls first.
  • Symlink Safety: Never rm -r symlink — it deletes through the link! Use just rm symlink.
  • Iterative Prompting: Ask v0 for one thing at a time for better results.
